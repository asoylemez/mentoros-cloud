Claude Bağlantısı

Kurumunuzun kendi Claude erişimini bağlayın. Kimlik bilgileri şifrelenerek saklanır ve bu ekrana bir daha gösterilmez.
Anahtar yoksa: console.anthropic.com → Settings → API Keys → Create Key
Bu, Claude.ai aboneliğinden ayrı bir şeydir; kullandığınız kadar ödersiniz.
AWS konsolunda Bedrock → Model access bölümünden Anthropic modellerine erişim izni almış olmanız gerekir.
Sunucuda önce şu komutun çalıştırılmış olması gerekir: gcloud auth application-default login
