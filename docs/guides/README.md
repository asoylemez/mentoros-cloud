# Kullanım kılavuzları (kaynaklar)

Uygulamadaki "Kullanım Kılavuzu (PDF)" düğmeleri `public/guides/` içindeki PDF'leri açar.
Bu klasör o PDF'lerin **kaynağıdır**:

| Kaynak (HTML) | PDF |
|---|---|
| `user-guide-tr.html` | `public/guides/user-guide-tr.pdf` |
| `user-guide-en.html` | `public/guides/user-guide-en.pdf` |
| `workspace-guide-tr.html` | `public/guides/workspace-guide-tr.pdf` |
| `workspace-guide-en.html` | `public/guides/workspace-guide-en.pdf` |

Ekran görüntüleri `img/` klasöründedir (örnek verilerle çekildi; gerçek kişi yok).

## Güncelleme
1. HTML dosyasındaki metni düzenleyin (gerekirse `img/` içindeki görseli değiştirin).
2. HTML dosyasını Chrome'da açın → Yazdır → "PDF olarak kaydet", kâğıt **A4**, "Arka plan grafikleri" açık.
3. PDF'i aynı adla `public/guides/` içine koyun (eskinin üzerine).

Son güncelleme: Kasım 2026 (V10).
